### ¿Qué cubre el 80% de los usuarios?

1.  Instalación ISO LinuxCNC 2.9 + Debian 12 Bookworm
2.  Latency Test y elección de kernel PREEMPT_RT
3.  MesaCT y configuración para PrintNC
4.  INI / HAL - entenderlo de una vez por todas
5.  Homing, límites, E-Stop y primer jog
6.  Husillo, THC plasma, láser y herramientas
