---
title: Cómo contribuir y usar el Harness
description: Flujo con DeepSeek
---

Usamos un harness propio en `/harness` para que DeepSeek pueda:

- Crear docs con frontmatter válido
- Editar docs existentes sin romper links
- Borrar y mover
- Crear categorías nuevas (ej. `grblhal`, `fluidnc`)
- Versionar con git

Ver documentación completa en `Harness / Introducción`.
